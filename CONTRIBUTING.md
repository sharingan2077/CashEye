# Contributing to CashEye

Thank you for considering a contribution.

## Before you start

- Search existing issues and pull requests to avoid duplicates.
- Open an issue first for substantial changes, so the proposed direction can be discussed.
- Never commit API keys, signing files, local properties, or production data.

## Pull requests

1. Create a focused branch from `main`.
2. Keep each pull request limited to one purpose and explain the user-visible impact.
3. Run the relevant checks locally when possible: `ktlintCheck`, `detekt`, unit tests, and lint.
4. Update documentation when behaviour, setup, or public interfaces change.

Pull requests are merged after review and a successful CI run. By contributing, you agree that your
changes are licensed under the repository's [MIT License](LICENSE).
