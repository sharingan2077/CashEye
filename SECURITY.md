# Security policy

## Supported versions

Security fixes are applied to the latest version on the `main` branch and the latest GitHub Release.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability
reporting feature for this repository. Include a description, affected version, reproduction steps,
and the potential impact. If private reporting is unavailable, contact the repository owner through
their GitHub profile without disclosing the exploit publicly.

We will acknowledge a report within 7 days and provide a status update after triage.
