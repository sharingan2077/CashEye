# Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless
of age, body size, disability, ethnicity, gender identity and expression, level of experience,
nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behaviour

- Be respectful, constructive, and welcoming.
- Give and accept feedback professionally.
- Focus discussion on the project and its community.

## Unacceptable behaviour

Harassment, discriminatory language, personal attacks, threats, publication of private information,
and other conduct that could reasonably be considered inappropriate are not tolerated.

## Enforcement

Project maintainers may remove, edit, or reject contributions and comments that do not follow this
Code of Conduct. Report concerns privately through the repository owner's GitHub profile.
